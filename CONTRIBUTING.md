# Contributing

Obrigado por querer contribuir com este projeto! Abaixo estão as orientações para abrir issues e pull requests de forma organizada.

## Código de Conduta
Se você pretende contribuir, espera-se que siga um comportamento respeitoso e colaborativo. Considere adicionar um CODE_OF_CONDUCT.md se precisar de regras formais.

## Como abrir uma Issue
- Verifique issues existentes para evitar duplicação.
- Título claro e objetivo.
- Descreva o problema ou a sugestão com passos para reproduzir (quando aplicável).
- Inclua ambiente (browser, versão do Node, SO) e prints ou links quando úteis.

## Como contribuir (Pull Requests)
1. Fork o repositório e crie um branch a partir de `main` (ex.: `feat/minha-melhoria` ou `fix/descrição-bug`).
2. Faça commits pequenos e com mensagens descritivas. Preferência por mensagens no estilo: `tipo: descrição curta` (ex.: `feat: adicionar formulário de contato`).
3. Rode os linters e testes locaismente antes de enviar.
4. Abra um Pull Request apontando para `main` no repositório original e descreva claramente as mudanças.

Checklist de PR:
- [ ] O PR tem uma descrição clara do que foi alterado e por quê.
- [ ] Inclui instruções para testar localmente, se aplicável.
- [ ] Não adiciona credenciais ou segredos no código.
- [ ] Segue a convenção de commits e estilo do projeto.

## Padrões de código e ferramentas
- Utilize formatação automática quando disponível (ex.: Prettier, ESLint, stylelint).
- Siga as convenções de nomeação e estrutura do projeto.
- Se o projeto tiver scripts de build/test, adicione instruções no README e rode localmente.

## Testes
- Adicione/atualize testes quando fizer alterações que afetem a lógica.
- Explique como rodar os testes no PR (comandos e pré-requisitos).

## Segurança / Secrets
- Nunca enviar chaves, senhas ou tokens em commits. Se um segredo vazar, revogue-o imediatamente.

## Revisão e Aprovação
- Um mantenedor revisará o PR. Pode solicitar mudanças; por favor, responda aos comentários ou atualize o PR.
- Após aprovação, um mantenedor pode mesclar o PR.

## Pequenas contribuições
- Correções de ortografia, documentação e pequenos ajustes são bem-vindos — ainda siga o fluxo de PR.

## Contato
