# Landing-page-1

Uma landing page simples hospedada em: https://landing-page-1-pearl.vercel.app

Descrição

Este repositório contém o código-fonte de uma landing page estática. Ele serve como ponto de entrada/mostruário para um projeto web simples.

Demo

- Demo: https://landing-page-1-pearl.vercel.app

Começando (local)

Pré-requisitos
- Node.js e npm (opcional, caso use ferramentas de build). Se a página for estática pura, não há dependências.

Instalação

1. Clone o repositório:
   git clone https://github.com/Jasta411/Landing-page-1.git
2. Abra o projeto no navegador (index.html) ou, se usar um servidor local:
   - Com Python 3: python -m http.server 8000
   - Com Live Server (VSCode) ou outra ferramenta de desenvolvimento.

Uso

- Edite os arquivos HTML/CSS/JS conforme necessário. O deploy atual está publicado via Vercel (ver link de demo acima).

Estrutura do projeto

- index.html - página principal (se presente)
- assets/  - imagens, estilos e scripts (se aplicável)
